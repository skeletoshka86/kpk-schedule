# КПК · Расписание

Приложение для студентов Android 8.0 и новее: расписание своей группы, время до пары и перемены, темы оформления и виджет рабочего стола.

Исходный код публикуется отдельным архивом `kpk-schedule-source.zip` в каждом релизе. Внутри — Java-код, ресурсы, инструкции сборки и проверки.

## Обновления приложения

Начиная с версии 1.3, открой настройки и нажми «Проверить обновления». Приложение покажет новую версию и список изменений, скачает APK после нажатия кнопки и откроет системную установку Android. При первом обновлении Android может попросить разрешение установки из этого приложения.

Версию 1.3 нужно один раз установить вручную поверх предыдущей. Настройки и сохранённое расписание сохраняются. Аккаунт GitHub на телефоне не нужен.

## Расписание

Автообновление Excel — в 07:00 и 20:00 по Москве, с возможными задержками Android. Его можно выключить в настройках; ручное обновление доступно всегда. После загрузки расписание доступно без интернета. Виджет после 15:00 показывает завтра.
